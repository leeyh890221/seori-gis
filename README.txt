서리 과업 대상지역 GIS 분석 (버전 1.0 데모) - 웹 게시용 파일

1. 이 폴더(seori_gis) 전체를 웹서버(회사 홈페이지 서버, GitHub Pages, Netlify 등)에 그대로 올립니다.
   index.html, parcels.json, img 폴더, sat 폴더가 같은 위치에 있어야 합니다.
2. 브라우저에서 올린 주소(예: https://도메인/seori_gis/)가 열리는지 확인합니다.
3. 그 주소를 알려주시면 FieldMappy GIS 분석 페이지에 iframe으로 넣어 드립니다.
   (웹서버가 다른 사이트 안에 넣는 것을 막는 설정(X-Frame-Options: DENY 등)이 없어야 합니다.)

※ 파일을 더블클릭해 PC에서 바로 열면 필지 자료(parcels.json)를 못 읽을 수 있습니다. 웹서버에 올려서 확인하세요.
본 자료는 2026년 소양강댐 양지천 유역 농업비점오염저감 용역에서 (주)휴먼플래닛이 작성한 자료입니다.
