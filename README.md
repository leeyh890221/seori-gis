방문자가 GIS 분석 탭을 열 때마다 최신 기초조사가 반영되고, '보고서 PDF 저장'도 그 내용으로 만들어집니다.

## 서버에서 할 일 (3가지)

### 1. 공개용 기초조사 API 추가
- 파일: `server/app/api/public/s/[site]/survey/[sub]/entries/route.ts` → FieldMappy 소스의 같은 경로에 추가
- 수정할 곳: 맨 위 `import { listEntries } ...` 를 FieldMappy에서 조사 기록을 조회하는 기존 함수로 바꿉니다.
  (현재 로그인용 `/api/s/soyang/survey/145/entries?form_id=...` 가 쓰는 조회 로직과 같으면 됩니다.)
- 공개 범위: `PUBLIC_FEEDS`에 적은 사이트·메뉴·양식(소양강댐 양지천 · 기초조사)만 열리고, 나머지는 404.
- 내보내는 필드: 기록 id 앞 8자리, 조사일, 조사자, 제목, 구분, 메모, 위도, 경도, 주소. 사진·연락처 등은 내보내지 않습니다.
- 확인: 브라우저(로그아웃 상태)에서 `https://fieldmappy.com/api/public/s/soyang/survey/145/entries` 를 열어
  `{"ok":true,"count":80,"data":[["01297faa","2026-11-17","이용현","15번 말단(밭)",...` 처럼 나오면 정상.

### 2. GIS 화면 파일 올리기
- 폴더: `public/gis/seori/` (index.html, parcels.json, img/, sat/) → FieldMappy 소스의 `public/gis/seori/` 에 그대로 복사
- 배포 후 주소: `https://fieldmappy.com/gis/seori/` (전체 화면), `https://fieldmappy.com/gis/seori/?embed=1` (탭 삽입용)
  - `?embed=1`: 상단 로고·헤드라인·회사정보를 빼고, 면적·필지·용수사용량 수치와 작성자 정보만 표시
- index.html은 열릴 때 `/api/public/s/soyang/survey/145/entries` 를 읽습니다. API가 실패하면 같은 폴더의 `entries.js`(있으면)를 대신 읽습니다.
- 정적 파일이 Next.js 미들웨어(사이트 경로 처리, 로그인 검사 등)에 걸리지 않도록 `/gis/` 경로는 제외해 주세요.

### 3. GIS 분석 탭 본문 바꾸기 (관리 화면에서)
- 관리 › 메뉴 관리 › 현장 기록 › GIS 분석 › 편집 → 본문을 `mdx/gis_page.mdx` 내용으로 교체 후 저장
- 바뀌는 점: iframe 주소가 GitHub(`leeyh890221.github.io/seori-gis/embed.html`) → `/gis/seori/?embed=1`
- 본문에는 바로가기 카드를 넣지 않습니다(상단 메뉴·첫 화면 버튼과 겹치므로).

### (참고) 첫 화면 바로가기
- 첫 화면에는 '우측 플로팅 바로가기' 배너로 **GIS 분석**(링크 `/s/soyang/survey/gis`, 아이콘 `mdi:map-search-outline`)을 이미 추가해 두었습니다. 관리 › 홈 콘텐츠 관리 › 우측 플로팅 바로가기에서 수정할 수 있습니다.
- 히어로의 '현장 기록 보기 / 지도 보기'와 겹치던 바로가기 카드(본문 2)는 꺼 두었습니다.

## 자동 반영 규칙 (index.html 안 `entryTargets`, `entryClass`, `applyEntries` 함수)
- 기준 데이터: 2026-11-24까지 정리한 80건과 수작업 지정(미조사 구간, 소실 필지, 축사 등)은 그대로 유지
- 새 기록이 들어오면
  - 필지 찾기: 제목의 필지 번호와 (논)/(밭) 표기 → 주소 지번 → 좌표가 들어 있는 필지 순으로 찾음
  - 분류: 메모에 과수 → 과수, 축사·우사·돈사·계사 → 축사, 소실·없어짐 → 소실, '논 작물'·벼·'논' → 논, 밭·작물·경작·고추·옥수수 등 → 밭
    (분류되면 미조사 구간에서 빠짐)
  - 토사유실: 유실·유출·토사·제방·붕괴 → 1순위, 경사·단차·우려 → 2순위 중점관리구간 자동 추가
- 기존 기록의 제목·메모 수정은 글자만 갱신(분류는 유지)
- 상단 수치, 분석 결과 요약, 필지 통계, 필지 목록, 토사유실 표, PDF 보고서가 모두 자동 계산
